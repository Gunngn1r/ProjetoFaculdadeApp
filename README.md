# 📱 Exemplo de AsyncStorage com React Native

Exercício da faculdade (Ciências da Computação · Estácio) para praticar armazenamento local em apps mobile. O usuário digita um texto, salva no aparelho e depois recupera o valor salvo, mesmo depois de fechar o app.

## O que pratiquei

- Salvar e ler dados no celular com AsyncStorage
- Funções assíncronas com `async` / `await`
- Estado com `useState` e componentes do React Native (TextInput, Button, Text)

## Tecnologias

- [React Native](https://reactnative.dev) com [Expo](https://expo.dev)
- TypeScript
- [@react-native-async-storage/async-storage](https://react-native-async-storage.github.io/async-storage/)

## Como rodar

```bash
git clone https://github.com/Gunngn1r/ProjetoFaculdadeApp.git
cd ProjetoFaculdadeApp
npm install
npx expo start
```

Leia o QR Code com o app **Expo Go** no celular.
